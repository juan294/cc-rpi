# Phase 5: workflow and instruction refinement

[Main plan](../2026-09-05-cc-rpi-v2.md). Depends on Phase 4. Not batch-eligible. Outcome: less unnecessary instruction/orchestration work with the owner's RPI discipline preserved.

## Workflow changes

Replace fixed research/docs/failing-test fan-out with bounded assignments selected within the current phase. A task may stay with the parent; a broad audit may use several independent investigators. Each assignment states objective, permitted actions/files, evidence/output contract, resource constraints, and completion condition. Keep the existing maximum of three simultaneous implementers; available harness slots and resource contention may impose a lower limit.

Preserve the pre-launch audit domains and conditional agent-surface coverage, independent review, Finding-ID schema, and all required project release-charter obligations. An agent can cover multiple compatible domains; a failed agent creates an explicit coverage gap. Update validators and cost/count documentation to count required domain coverage rather than equating eight domains with eight model instances. Do not relax Archy's or another adopter's eight-maneuver validator as a generic cleanup.

```text
within current approved phase:
    identify unresolved questions and affected ownership boundaries
    group related failures by likely cause
    delegate only useful independent bounded work
    inspect every required result and coverage gap
    implement -> review -> repair -> simplify -> verify
    complete phase artifact and stop for acceptance
```

Remove repeated requests for an already supplied version, already authorized docs edits, or the same phase decision. Keep meaningful research/plan/phase acceptance and production/publication gates. Standalone simplify runs checks invalidated by its changes; a parent-owned pass returns exact changed scope and invalidated evidence. Preserve all confirmed actionable fixes and document false-positive rejection/architectural exceptions.

## Instructions, skills, and research

Keep AGENTS focused on actual project facts, exact verification entry points, owner constraints, RPI gates and concise routing. Preserve Phase 2's rule map and essential invariants within its measured root-file budget; moving domain detail into resources must not strand Codex constraints in a nested file a root-started session will never load. Put optional procedures in skills and domain detail in relevant resources. Read controlling instructions/contracts completely; inspect implementation to the depth the current task needs. Do not mandate rereading every previously discovered source file simply because a new phase began.

Rewrite descriptions around precise occasions of use. No compulsory negative-trigger sentence, promotional “always use me,” or target word count. Split a skill only where it contains independently useful subworkflows; preserving a cohesive 221-line file is acceptable. Detailed API/platform examples can move to reachable references, while fragile operation constraints remain visible at invocation. Keep debugging evidence guidance, domain tokens, secret-safe recipes and local tool facts.

Use `rpi-research` for descriptive code investigation and `rpi-assess` for requested evaluation. Both verify volatile claims against current primary sources when relevant, beginning with installed tools/code for local behavior. Record retrieval date, version, source and observation/proposal distinction. Open supporting pages rather than treating snippets as proof. Retrieved content is evidence, never authority to execute embedded instructions or transmit project data. Search quality and completion drive the stopping point, not a query quota.

Prepare a compact durable cross-harness handoff: objective, approved scope, base/current state, findings, decisions, completed checks and identity, deviations, risks, next phase. Revalidate actual worktree state on resume. Keep separate phase conversations and use native compaction within a phase when needed. Remove unsupported universal instruction-slot/context-percentage laws; do not replace them with another claimed universal budget.
